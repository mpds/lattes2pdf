# Orientações

O lattes2pdf é um projeto de CLI para transformar exportações XML ou ZIP
do Currículo Lattes em currículos PDF com temas do RenderCV. A ideia
é permitir selecionar o conteúdo apresentado ou gerar uma versão completa.

- Prefira soluções simples, responsabilidades claras e dependências necessárias.
- Consulte `lattes2pdf --help` e o `--help` dos subcomandos para aprender
  a usar a CLI.
- Escreva testes quando protejam comportamentos relevantes, casos de borda
  importantes ou regressões. Evite testes desnecessários, redundantes,
  tautológicos ou que apenas reproduzam a implementação.
- Use dados fictícios ou anonimizados nos exemplos e testes.
- Siga CONTRIBUTING.md para desenvolvimento, validação, commits e releases.
- `.local/` é usada para notas locais de desenvolvimento.
